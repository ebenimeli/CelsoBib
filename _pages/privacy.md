- Responsable: Enrique Benimeli (propietario de esta web).
- Finalidad: Los datos facilitados mediante el formulario de contacto se utilizan únicamente para responder a la consulta enviada.
- Legitimación: El consentimiento del usuario al enviar el formulario.
- Destinatarios: No se comunicarán datos a terceros, salvo obligación legal.
- Derechos: Puedes acceder, rectificar y suprimir tus datos escribiendo a contacto (at) ebenimeli (dot) org.
- Conservación: Los datos se eliminarán una vez resuelta la consulta o transcurrido un tiempo razonable.
- Información adicional: En esta web no se utilizan cookies de seguimiento ni se realiza perfilado de usuarios.
